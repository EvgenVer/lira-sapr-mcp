## Ревью этапа

Свежий субагент проверил код этапа (43b1ffc..016c888). Исправлено сразу:

- откат из копии закрывал открытую модель до проверки копии: при опечатке в пути копии
  несохранённые изменения терялись, а модель оставалась закрытой. Теперь копия
  выбирается до закрытия, модель открывается снова и при ошибке копирования, копирование
  идёт вне цикла событий сервера;
- отмена вызова клиентом (Esc, отключение) больше не оставляет задание в очереди, чтобы
  оно незаметно выполнилось позже; уже выполняемое задание помечается просроченным;
- гонка при тайм-ауте: задание, закончившееся в момент тайм-аута, навсегда оставляло
  отметку «ещё выполняется», и все следующие задания выглядели просроченными. Отметку и
  её снятие теперь разделяет блокировка, а закончившееся задание сразу записывается в
  итог;
- «припаркованный» текстовый файл другого процесса сервера (например, Claude Desktop и
  Claude Code одновременно) мог вернуться на место во время чужой выгрузки и потеряться.
  В имени теперь номер процесса, и возвращаются только файлы завершившихся процессов;
- `backup_dir_name = ".."` клал копии в папку выше модели — теперь ошибка настроек;
- у функции DPI задан тип результата (дескриптор, не целое).

Остальное — в техническом долге `TASKS.md`. Проверки: `pytest` 126 passed;
`ruff check` чист; живой тест картинки не запускался — окно ЛИРЫ было свёрнуто
владельцем, захват с учётом DPI проверен на панели задач Windows (1920 пикселей в ширину).
