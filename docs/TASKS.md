## Technical debt

- medium — результаты ЛИРЫ лежат в папке Work под именем модели: одноимённые модели из
  разных папок перезаписывают результаты друг друга; сервер предупреждает о моделях,
  рассчитанных в этой сессии, а сводка — о расхождении числа узлов и элементов; правку
  без изменения их числа не видно (у ЛИРЫ нет отметки «результаты устарели» в API) —
  `tools/results.py`, `services/models.py` — found 2026-10-27
- medium — суммарная форма динамического загружения (SummaryShapeCount = 1) через
  LiraResAPI не адресуется: позиции 0 и N+1 дают ошибку, флаг ForcesSum ничего не
  меняет; агент получает только отдельные формы — `adapters/results.py` — found
  2026-10-27
- medium — нагрузки на фрагмент и продавливание написаны по описанию API и не проверены
  на живой модели: в учебных моделях нет фрагментов и контуров продавливания; нужна
  модель с ними (адресация форм динамики там тоже не проверена) —
  `adapters/results.py` — found 2026-10-27
- low — правка нагрузок отклоняется у моделей по нормам сочетаний не по умолчанию
  (не СП 20.13330, например СНиП) и у моделей со стадиями монтажа; отказ понятный,
  модель не меняется — владелец согласен (2026-10-29); возможные пути — шаблон,
  сделанный вручную, и API 2025+ — `services/loads.py` — found 2026-10-27; 2026-10-29:
  модели по СП 20 теперь правятся (виды возвращаются записью `LoadCases`), было high
- low — если после закрытия исходной модели не удалось сохранить новую, `set_loads`
  оставляет исходную закрытой (файл цел); открывать её снова — `services/loads.py` —
  found 2026-10-27 (ревью этапа 1)
- low — `lira_copy_stiffness` переписывает всю таблицу `Stiffnesses` (запись только
  новой строки по номеру не проверена); потеря при чтении-записи изменит все жёсткости;
  в живом тесте одна жёсткость — `services/operations.py` — found 2026-10-27 (ревью
  этапа 2)
- low — `add_elements` не атомарна: если ЛИРА отклонит жёсткости, элементы останутся

- low — адаптер импортирует сервис скриптов (`ComLiraAdapter.run_script`); вынести в

- low — выгрузка пишет по любому абсолютному пути (в т.ч. сетевому) и заменяет
