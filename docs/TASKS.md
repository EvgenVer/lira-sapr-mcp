## Technical debt

- high — правка нагрузок существующих моделей отклоняется, если их нормы сочетаний
  отличаются от норм ЛИРЫ по умолчанию (импорт текста их сбрасывает); искать способ
  задать нормы (документ 0 текстового формата, API 2025+) — `services/loads.py` —
  found 2026-10-27
- medium — результаты ЛИРЫ лежат в папке Work под именем модели: одноимённые модели из
  разных папок перезаписывают результаты друг друга; сервер предупреждает о моделях,
  рассчитанных в этой сессии, а сводка — о расхождении числа узлов и элементов; правку
  без изменения их числа не видно (у ЛИРЫ нет отметки «результаты устарели» в API) —
  `tools/results.py`, `services/models.py` — found 2026-10-27
- medium — COM-поток не может прервать уже выполняемое задание: после тайм-аута агенту
  сказано «ошибка», а правка (например, `lira_set_loads`) может завершиться позже;
  для пишущих операций отвечать «ещё выполняется, проверьте позже» — `com/worker.py`,
  `tools/tables.py` — found 2026-10-27 (ревью этапа 1)
- medium — удаление временной таблицы в `finally` не обёрнуто в `_call`: его ошибка
