# Исследование: API ЛИРА-САПР

Дата: 2026-10-27. Источники: библиотеки типов установленной ЛИРА-САПР 2024 R2 (Update R2.3),
документация на rflira.ru и lira.land, релиз-ноты.

## Готовые MCP-серверы

Публичных MCP-серверов для ЛИРА-САПР / ЛИРА-САПФИР не найдено: ни на GitHub, ни в
каталогах MCP, ни у разработчика. Python-обёрток над API тоже не найдено.

## Какие программные интерфейсы есть

ЛИРА-САПР предоставляет три независимых COM-интерфейса. COM (Component Object Model) — механизм
Windows, через который одна программа вызывает объекты другой; из Python он доступен через
библиотеки `pywin32` или `comtypes`.

| Интерфейс | Где живёт | ProgID / библиотека типов | Назначение |
|---|---|---|---|
| ЛИРА-САПР API (ВИЗОР) | `Bin\x64\LiraSapr.exe`, отдельный процесс | `LiraSapr.Application` (2024); в 2025 — `LiraSapphire.Application` | Открыть/создать/сохранить модель, таблицы ввода, выделение, запуск расчёта, CSV-результаты, импорт файлов |
| RES API (результаты) | `Bin\x64\LiraResAPI.dll`, загружается в процесс клиента | `LiraSaprRes` | Чтение результатов расчёта: перемещения, усилия, РСУ, РСН, периоды колебаний, подобранная арматура, нагрузки на фрагмент, продавливание |
| САПФИР API | `Sapfir 2024\SAPFIR.tlb` | `Sapfir.Application.2024.0` | Архитектурная (BIM) модель: стены, плиты, колонны, этажи, оси; около 50 объектов автоматизации |

Полные выгрузки библиотек типов: [LiraSapr-2024R2.txt](typelib/LiraSapr-2024R2.txt),
[LiraResAPI-2024R2.txt](typelib/LiraResAPI-2024R2.txt).

## Что умеет ЛИРА-САПР API 2024 R2

- **Приложение**: `OpenDocument`, `CreateNewDocument`, `ImportFile` (импорт файла с шаблоном модели),
  `StartAnalysis` (асинхронно, события `AnalysisStarting/Finished/Stopped`),
  `StartAnalysisOnServer`, `StopAnalysis`, `DeleteResults`, `StartZip/StartUnzip` (архивы),
  `StartCmd` (любая команда меню по идентификатору), единицы измерения.
- **Документ**: `Save/SaveAs/Close`, выделение узлов и элементов, текущее загружение,
  собственный вес (`SetDeadWeightLoad`), модель грунта (`SetSoilModel`),
  генерация CSV-таблиц результатов при расчёте (`SetGenerateCsvTables`, около 80 видов таблиц).
- **Таблицы ввода** (чтение и запись двумерным массивом, `Apply` возвращает ошибки по строкам):
  координаты узлов, элементы (тип и узлы), связи, жёсткости и их назначение, коэффициенты постели C1/C2,
  жёсткие вставки, шарниры, объединение перемещений, локальные оси, монтажные стадии,
  РСН, загружения, массы, координационные оси, высотные отметки, конструктивные блоки,
  материалы конструирования.

## Пробелы и риски

- **Нет таблицы ввода нагрузок** на узлы и элементы. Возможные обходы: импорт текстового
  формата ЛИРА через `ImportFile`, таблица усилий для стержней, команды меню. Требует проверки.
- **РСУ** (расчётные сочетания усилий) отдельной таблицы ввода не имеют — проверить, как задавать.
- Многие методы могут показывать диалоги ("Messages from UI can be shown"); модальное окно
  остановит автоматизацию. Нужна стратегия: тайм-ауты, обнаружение зависания.
- ProgID и имя библиотеки типов сменились между 2024 и 2025 (`LiraSapr` → `LiraSapphire`).
- Нужна лицензия (ключ Guardant) и запущенный графический интерфейс ЛИРА; одна машина Windows.
- Документация методов — только описания внутри библиотеки типов; формат параметров таблиц
  нужно изучать, заполняя таблицы вручную в интерфейсе.

## История API по версиям

| Версия | Что известно |
|---|---|
| 2021 R1 | API впервые объявлено ("технология API"); IronPython-ноды в САПФИР-Генераторе |
| 2022 R2 Update 3 | Добавлены импорт файлов и генерация результатов в CSV |
| 2024 R1 | Новые таблицы ввода: оси, высотные отметки, конструктивные блоки, материалы |
| 2025 | Расширены создание/корректировка модели и доступ к результатам, плагины |
| 2026 | Вышла; изменения API не изучены |

Вывод: ЛИРА 2021 даёт только таблицы ввода без импорта и CSV; полноценный цикл
"создать → рассчитать → выгрузить" складывается начиная с 2022 R2 U3, а с удобными таблицами
осей и материалов — с 2024 R1.
