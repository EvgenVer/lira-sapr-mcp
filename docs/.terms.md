*[MCP]: Model Context Protocol — стандарт, по которому ИИ-агент подключается к внешним инструментам
*[COM]: Component Object Model — механизм Windows, через который одна программа управляет объектами другой
*[stdio]: стандартный ввод-вывод процесса; так MCP-клиент общается с локальным сервером
*[РСУ]: расчётные сочетания усилий
*[РСН]: расчётные сочетания нагрузок
*[ProgID]: имя, под которым COM-программа зарегистрирована в Windows, например LiraSapr.Application
*[pywin32]: библиотека Python для работы с COM и функциями Windows
*[uv]: менеджер окружений и пакетов Python
*[LiraResAPI]: библиотека ЛИРЫ для чтения результатов расчёта из файлов в рабочей папке
*[readOnlyHint]: признак инструмента MCP: инструмент только читает и ничего не меняет
*[MCP-ресурс]: документ или данные, которые MCP-сервер отдаёт агенту для чтения (в отличие от инструмента, который выполняет действие)
