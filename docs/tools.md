# Инструменты

Сервер даёт агенту 41 инструмент. Агент сам выбирает нужный по описанию, которое сервер
передаёт ему на английском; здесь — что делает каждый, по-русски. Если модель не
указана, инструмент работает с активной моделью ЛИРЫ. Единицы — текущие единицы ЛИРЫ
(их показывает `lira_model_summary`).

Если версия ЛИРЫ не умеет то, что нужно инструменту, он отвечает понятной ошибкой, а
`lira_status` перечисляет такие инструменты.

## Состояние и модели

| Инструмент | Что делает |
|---|---|
| `lira_status` | Найденные версии ЛИРЫ, какая используется, подключена ли; возможности API этой версии и инструменты, которые она не выполнит. ЛИРУ не запускает |
| `lira_list_models` | Открытые в ЛИРЕ модели: имя, путь, тип, есть ли несохранённые изменения, какая активна |
| `lira_open_model` | Открыть файл `.lir` (запускает ЛИРУ, если нужно) |
| `lira_create_model` | Создать пустую модель заданного типа |
| `lira_save_model` | Сохранить модель, в том числе под новым именем |
| `lira_close_model` | Закрыть модель |
| `lira_model_summary` | Сводка: тип схемы, единицы, число узлов и элементов, типы КЭ, жёсткости, загружения, есть ли результаты |
| `lira_model_picture` | Картинка модели в PNG — как её рисует ЛИРА |

## Резервные копии

| Инструмент | Что делает |
|---|---|
| `lira_list_backups` | Копии модели, которые сервер сделал перед первой правкой |
| `lira_restore_backup` | Вернуть копию на место модели (текущий файл тоже сохраняется копией) |

## Таблицы ввода и текстовый формат

| Инструмент | Что делает |
|---|---|
| `lira_list_input_tables` | Таблицы ввода, которые поддерживает эта версия ЛИРЫ |
| `lira_read_table` | Строки таблицы ввода (все или по номерам) |
| `lira_write_table` | Записать строки в таблицу ввода и применить к модели; ошибки ЛИРЫ возвращаются по строкам |
| `lira_export_text` | Вся модель в текстовом формате ЛИРЫ |
| `lira_import_text_model` | Создать модель из текстового формата и сохранить в `.lir` |
| `lira_read_loads` | Нагрузки модели (из текстовой выгрузки) |
| `lira_set_loads` | Заменить нагрузки сохранённой модели — всех или указанных загружений. Сервер пересобирает модель из текста, возвращает все таблицы ввода, сверяет их и только потом перезаписывает файл. Модель по нормам сочетаний не по умолчанию (не СП 20.13330, например СНиП) отклоняется: после пересборки ЛИРА не может вернуть её виды загружений |

Справочник столбцов таблиц, кодов типов КЭ и текстового формата агент читает как ресурс
`lira://reference/tables`.

## Правка операциями

| Инструмент | Что делает |
|---|---|
| `lira_add_nodes` | Добавить узлы по координатам |
| `lira_add_elements` | Добавить элементы одного типа КЭ по узлам, с жёсткостью |
| `lira_set_stiffness` | Назначить жёсткость элементам (списком или диапазонами, например «1-10 15») |
| `lira_copy_stiffness` | Создать жёсткость как копию существующей с изменёнными параметрами |
| `lira_set_restraints` | Задать связи в узлах по направлениям X Y Z UX UY UZ |
| `lira_self_weight` | Добавить собственный вес в загружение (или удалить его) |

## Расчёт

| Инструмент | Что делает |
|---|---|
| `lira_run_analysis` | Запустить расчёт сохранённой модели и дождаться его (или вернуться сразу) |
| `lira_analysis_status` | Состояние последнего расчёта: идёт, закончен, с ошибкой, остановлен |
| `lira_stop_analysis` | Остановить расчёт |
| `lira_analysis_protocol` | Протокол решателя с предупреждениями |
| `lira_delete_results` | Удалить результаты расчёта модели |

## Результаты

Сервер не отдаёт таблицы целиком: он возвращает экстремумы и N наибольших строк, а
полную таблицу по запросу пишет в CSV или Excel. Есть отбор по порогу и огибающие по
загружениям.

| Инструмент | Что делает |
|---|---|
| `lira_node_displacements` | Перемещения узлов по загружениям (для динамики — по формам и суммарные, `shape: "sum"`) |
| `lira_element_forces` | Усилия и напряжения элементов всех типов КЭ по загружениям (для динамики — по формам и суммарные, `shape: "sum"`) |
| `lira_load_combinations` | Список РСН модели: номер, имя, формула, особое, сейсмическое |
| `lira_combination_displacements` | Перемещения узлов в РСН |
| `lira_combination_forces` | Усилия и напряжения в РСН по предельным состояниям |
| `lira_design_forces` | РСУ: сочетания, критерии, группы, состав загружений |
| `lira_periods` | Периоды, частоты, модальные массы и коэффициенты участия форм |
| `lira_reinforcement` | Подобранная арматура железобетонных элементов |
| `lira_fragment_loads` | Нагрузки на фрагмент |
| `lira_punching_loads` | Нагрузки на контуры продавливания |

## Окна ЛИРЫ

| Инструмент | Что делает |
|---|---|
| `lira_dialogs` | Модальные окна, которые сейчас показывает ЛИРА: заголовок, текст, кнопки |
| `lira_press_dialog_button` | Нажать кнопку окна ЛИРЫ по её тексту |

## Скрипт агента

| Инструмент | Что делает |
|---|---|
| `lira_run_script` | Выполнить Python-код агента внутри сервера с объектами ЛИРЫ — для всего, что не покрыто инструментами. Перед этим сервер делает копию модели |

`lira_run_script` даёт агенту полный доступ к ЛИРЕ, Python и файлам компьютера. Он
включён по умолчанию; флаг `--no-scripts` в команде запуска убирает его — см.
[Эксплуатацию](operations.md).
