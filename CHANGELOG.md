# Изменения

## Не выпущено

- `lira_set_loads` правит нагрузки моделей с нормами сочетаний ЛИРЫ по умолчанию
  (СП 20.13330) с любыми видами загружений: виды, которые путает импорт текста,
  возвращаются. Отказ остаётся для моделей по другим нормам (например, СНиП) и теперь
  понятен для моделей со стадиями монтажа.

## 0.1.0 — 2026-10-28

Первая публичная версия. Проверена на ЛИРА-САПР 2024 R2.3; ЛИРА 2025 и 2026 должны
работать тем же кодом, но ещё не проверены.

- 41 инструмент: модели (открыть, создать, сохранить, закрыть, сводка, картинка),
  таблицы ввода, текстовый формат и нагрузки, правка операциями (узлы, элементы,
  жёсткости, связи, собственный вес), расчёт, результаты (перемещения, усилия и
  напряжения, РСН, РСУ, периоды, арматура, нагрузки на фрагмент и продавливание),
  окна ЛИРЫ, скрипт агента. Список — [docs/tools.md](docs/tools.md).
- Результаты компактно: экстремумы, N наибольших строк, отбор по порогу, огибающие;
  полные таблицы — файлом CSV или Excel.
- Резервная копия модели перед первой правкой и откат из неё.
- Инструмент, которому нужна функция API, отсутствующая в этой версии ЛИРЫ, отвечает
  понятной ошибкой; `lira_status` перечисляет такие инструменты.
- `lira-sapr-mcp --diagnose` — отчёт об установленных ЛИРАХ и их API для поддержки
  новых версий.
- `--no-scripts` — запуск без инструмента скриптов.
- Установка через `uvx` с GitHub.

Известные ограничения: нагрузки моделей с нормами сочетаний не по умолчанию сервер не
меняет; одноимённые модели из разных папок делят результаты в папке ЛИРЫ.
